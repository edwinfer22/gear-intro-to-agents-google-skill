    Fundamentos de producción

    De una idea a un agente fiable

    Un agente combina un modelo con instrucciones, contexto y herramientas. Para llevarlo a producción, diseña el flujo completo: qué puede decidir, qué puede hacer y cómo se comprueba cada resultado.

    1. Define el objetivo

    Acota la tarea, sus entradas, el resultado esperado y los casos en que el agente debe detenerse o pedir aclaraciones.

    2. Prepara el contexto

    Entrega instrucciones relevantes y fuentes autorizadas. Recupera solo los datos necesarios y conserva su procedencia para poder verificarlos.

    3. Conecta herramientas

    Expón acciones concretas con contratos claros, validación de parámetros y permisos de mínimo privilegio; confirma antes de acciones sensibles.

    4. Evalúa y observa

    Mide calidad, finalización, latencia, coste y errores. Registra llamadas a herramientas y usa pruebas repetibles para mejorar con seguridad.

    Antes del lanzamiento

    Lista de verificación para producción

    La autonomía debe crecer al mismo ritmo que la observabilidad y los controles. Revisa estos puntos antes de ampliar el acceso o automatizar acciones de impacto.

    Pruebas con casos reales

    Incluye casos normales, entradas ambiguas, datos incompletos y errores de herramientas. Define criterios de aceptación medibles antes de cambiar prompts o modelos.

    Permisos y datos mínimos

    Separa lectura de escritura, limita cada conector a los recursos necesarios y evita enviar información personal si no aporta valor a la tarea.

    Aprobación y recuperación

    Solicita confirmación en operaciones irreversibles o externas. Diseña cancelación, reintentos acotados y una salida segura cuando el servicio no responde.

    Monitoreo y mejora

    Registra resultados, duración, coste y llamadas a herramientas con protección de datos. Revisa fallos periódicamente y conserva una forma de volver a una versión estable.

    Glosario esencial

    Vocabulario de agentes

    Conceptos clave para conversar sobre diseño, integración y operación de sistemas agénticos.

    Agente
    Sistema que interpreta un objetivo, decide pasos y puede usar herramientas para actuar dentro de límites definidos.
    Tool calling
    Mecanismo por el que el modelo propone una llamada estructurada y la aplicación valida y ejecuta la herramienta.
    Orquestación
    Coordinación del modelo, contexto, herramientas y estado para completar un flujo de trabajo de principio a fin.
    Grounding
    Fundamentar una respuesta con fuentes concretas y pertinentes, en vez de depender solo del conocimiento general del modelo.
    RAG
    Generación aumentada por recuperación: busca información autorizada y relevante, y la aporta como contexto antes de responder.
    MCP
    Protocolo abierto que estandariza cómo los clientes descubren y utilizan herramientas y recursos de servidores compatibles.
    Skill
    Paquete reutilizable de instrucciones, conocimiento y pasos para realizar una tarea especializada de manera consistente.
    Mínimo privilegio
    Principio de otorgar a cada usuario o herramienta únicamente el acceso necesario para su función.
    Human-in-the-loop
    Punto de revisión donde una persona valida o autoriza una decisión antes de que el agente continúe.
